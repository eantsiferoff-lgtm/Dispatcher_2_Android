# Official Documents

## Workflow

1. Determine addressee, purpose and desired outcome.
2. Extract facts from supplied text/files before asking for missing information.
3. Do not invent document numbers, dates, approvals, legal provisions or requisites.
4. Check current law/regulations when the legal basis materially affects the document.
5. Draft in clear, professional Russian with minimal repetition.
6. Structure the request and supporting facts so the recipient can act on it.
7. If the user asks for Word/PDF, create the requested file when tools allow.

## Typical structure

- addressee;
- applicant/sender;
- document title;
- relevant facts/circumstances;
- issue or basis;
- request/proposal;
- attachments;
- date/signature placeholders when not provided.

Deliver finished reusable text, not merely an outline.
