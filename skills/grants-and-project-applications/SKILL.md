# Grants and Project Applications

## Workflow

1. Read the current competition/program rules and source materials.
2. Build a checklist of required documents and eligibility constraints.
3. Map available evidence to each requirement.
4. Flag missing approvals or evidence instead of inventing them.
5. Prepare, as applicable:
   - problem statement;
   - project goal and tasks;
   - target groups/beneficiaries;
   - technical description;
   - expected effects and measurable indicators;
   - schedule;
   - budget;
   - risks and mitigation;
   - support/cover letters;
   - required attachments.
6. Keep all key numbers consistent across every file.
7. Before final delivery, run a package-wide consistency check.

## Critical consistency fields

Pay special attention to population/beneficiaries, length/area, costs, dates, coordinates,
technical parameters and organization names.
